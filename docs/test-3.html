Marking scheme

Mark strictly against these answers. Award a mark only where the required working or point is present. For maths and physics, a correct answer with no working scores nothing.

Q1 — model answer

Volume ratio $=3^3:5^3=27:125$

Q2 — model answer

$t=5.0 imes60=300\ ext{s}$; $Q=It=2.0 imes300=600\ ext{C}$.

Charge = 600 C (2 s.f.).

Q3 — model answer

$E=QV=2.0 imes6.0=12\ ext{J}$.

Energy = 12 J (2 s.f.).

Q4 — model answer

East component $=5\sin60° = 5\times0.866 = 4.33$ km

Q5 — model answer

The writer uses a minor, one-word sentence (1). This abruptly halts the sentence, giving the failure a final, absolute quality and emphasising the totality of the collapse (1).

Q6 — model answer

$A=\tfrac12(8)(11)\sin40° = 44\times0.6428 = 28.3\text{ cm}^2$

Q7 — model answer

$R=\dfrac{V}{I}=\dfrac{12}{3.0}=4.0\ \Omega$.

Resistance = 4.0 $\Omega$ (2 s.f.).

Q8 — model answer

$R_T=R_1+R_2=3+7=10\ \Omega$.

Total resistance = 10 $\Omega$.

Q9 — model answer

1) Water-soluble vitamins and minerals are not lost into the cooking water, so it is more nutritious. 2) The vegetables keep their colour, flavour and a firm bite texture instead of going soft and watery.

Q10 — model answer

$\sqrt{16+25+49}=\sqrt{90}=3\sqrt{10}$

Q11 — model answer

Effective: the headline uses dramatic language, e.g. 'battle' (1), which frames the issue as a conflict the reader has a stake in (2), making them want to read on (3).

Q12 — model answer

It must carry the required weight without the straps breaking; it must protect the contents from rain.

Q13 — model answer

The smartphone — touchscreen and mobile data technology made it possible before consumers had asked for it.

Q14 — model answer

To test the grip and comfort in the hand before manufacture; to check the shape and size are ergonomically suitable cheaply and quickly.

Q15 — model answer

In first-angle projection the view is placed on the opposite side of the object; in third-angle projection the view is placed on the same side as the object being viewed.

Q16 — model answer

A resilient performer refocuses quickly instead of dwelling on the mistake (1), so they maintain technique and decision quality rather than letting one error cause more (2).
